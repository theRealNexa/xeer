# xeer
Xeer is a modern reading web app for PDFs and EPUBs with a customizable reading experience. It supports dark/light mode, font controls, page or scroll view, file search, pinned books, and persistent per-file reading settings with a saved library across sessions.
📚 Xeer

Xeer is a modern, feature-rich web reader for PDFs and EPUBs designed for a smooth, customizable, and distraction-free reading experience.

✨ Features

Xeer is built to give readers full control over how they consume digital books:

📖 Reading Experience
Support for PDF and EPUB files
Scroll view or page-by-page navigation
Smooth rendering for long-form reading
🎨 Customization
Dark mode / Light mode
Adjustable font size
Change between predefined fonts
Bold text mode for improved readability
💾 Smart Persistence
Saves reading progress per file
Remembers user settings for each document
Persistent library (data survives refresh)
📂 Library System
Add and manage multiple books
Files remain saved across sessions
Pin up to 3 favorite books
🔍 Search
Search through your entire library instantly
🧠 Core Idea

Xeer is built around a simple philosophy:

“Reading should adapt to the reader — not the other way around.”

It focuses on personalization, speed, and continuity across sessions.

⚙️ Tech Stack
React (Vite)
TypeScript
TailwindCSS
shadcn/ui component system
LocalStorage for persistence
🚀 Getting Started
1. Clone the repository
git clone https://github.com/theRealNexa/xeer.git
2. Install dependencies
npm install
3. Run development server
npm run dev
4. Build for production
npm run build
📦 Deployment

Recommended deployment: Netlify

Build command:
npm run build
Publish directory:
dist
